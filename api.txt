GET / health - 서버 상태 점검
구분    내용
요청    없음
응답(JSON) { "status":"ok"}

응답    타입    설명
status  string  보통"ok"


POST / chat - llm과 채팅
구분    내용
요청(JSON)  { "persona": 응답 페르소나 }
요청(JSON)  { "question": "(사용자 입력) 점심 메뉴는 무엇으로 할까요?" }
응답(JSON)  { "answer": "..." }
동작    사용자가 보낸 텍스트에 llm이 대답.

응답    타입    설명
answer  string  llm의 답변


POST / ask_gemini - Gemini REST API 호출
구분    내용
요청(JSON)  { "systemInstruction": "시스템 지침", "contents": "사용자 입력", "generationConfig": { "temperature": 0.7 } }
응답(JSON)  { "answer": "..." }
동작    세 입력값을 하나의 JSON으로 받아 Gemini generateContent 요청을 만들고 LLM의 텍스트 응답을 반환.

응답    타입    설명
answer  string  Gemini의 답변


=== 서비스 API (KAN-47) ===

GET /personas - persona 목록 조회 (KAN-58)
요청    없음
응답(JSON)  { "personas": [ { "id": "doyun", "description": "...", "voice_id": null } ] }
동작    app/prompts/bundles/personas/*.yaml 을 스캔해 목록을 반환.

GET /scenarios - 시나리오 목록 조회 (KAN-59)
요청    없음
응답(JSON)  { "scenarios": [ { "id": "interview", "description": "면접 상황 대화 연습" } ] }
동작    app/prompts/modes/*.yaml 을 스캔해 목록을 반환.

POST /rooms - 채팅방 생성 (KAN-60)
요청(JSON)  { "user_id": "u1", "persona_id": "doyun", "scenario_id": "interview", "title": "면접 연습" }
응답(JSON)  201 { "id", "user_id", "persona_id", "scenario_id", "title", "created_at" }
오류    400 알 수 없는 persona_id / scenario_id

GET /rooms?user_id=u1 - 채팅방 목록 조회 (KAN-61)
응답(JSON)  { "rooms": [ ... ] }   // 최신 생성순
오류    422 user_id 누락

GET /rooms/{room_id}/messages - 채팅 내역 조회 (KAN-62)
응답(JSON)  { "messages": [ { "id", "role", "content", "created_at" } ] }  // 오래된 순
오류    404 채팅방 없음

POST /rooms/{room_id}/messages - 채팅 메시지 전송 (KAN-65)
요청(JSON)  { "question": "안녕하세요" }
응답(JSON)  { "answer": "...", "message": { ...assistant 메시지... } }
동작    사용자 메시지를 저장하고, 방의 persona와 최근 50건 이력으로 LLM 답변을 생성해 저장.
오류    400 빈 질문 / 404 채팅방 없음 / 502·503·504 LLM 오류

POST /rooms/{room_id}/feedback - 채팅 피드백 요청 (KAN-63)
요청    없음
응답(JSON)  { "score": 80, "summary": "...", "improvements": ["..."] }
동작    방의 전체 대화를 LLM에 보내 사용자 말투의 예절/매너를 평가.
오류    400 사용자 발화 없음 / 404 채팅방 없음

POST /tts - 음성 듣기 요청 (KAN-64)
요청(JSON)  { "text": "안녕하세요", "persona_id": "doyun" }
응답(JSON)  { "audio": "<base64>", "mimeType": "audio/mpeg", "voice_id": "..." }
동작    ElevenLabs TTS로 음성을 합성해 base64로 반환. persona YAML의 voice_id → ELEVENLABS_VOICE_ID 순으로 음성 선택.
오류    400 알 수 없는 persona / 503 API키·음성 미설정 / 502·504 업스트림 오류
